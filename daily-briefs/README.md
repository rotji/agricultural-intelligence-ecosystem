# Daily Brief Archive

Store complete daily intelligence reports here as dated Markdown files, for example:

- BRF-2026-11-19.md
- BRF-2026-11-20.md

Preserve each report as issued, with its research cutoff, source citations, evidence qualifications, coverage gaps and original findings.

Do not silently replace an earlier report when new information appears. Add a dated correction or update and link it to the relevant opportunity, action or investigation IDs.

The archive is a historical record, not the current state register. The current state belongs in registers/.
