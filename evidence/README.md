# Evidence Archive

Use this directory for durable source records or evidence indexes where useful.

For each evidence record, capture:
- Stable ID (EVD-XXXX).
- Source organisation/person/platform and title.
- URL or retrieval location.
- Publication date and observation/collection date.
- Relevant geography and product/form.
- Exact claim or observation supported.
- Evidence level (L1–L4) and confidence.
- Verification method and limitations.
- Licensing/usage constraints where known.
- Related opportunity, action, investigation and decision IDs.

Preserve original provenance. Do not represent a source-reported claim as independently verified. Keep confidential or personal data out of public repository records unless there is a lawful and justified reason to include it.
